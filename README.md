# Microrage Website Clone

A responsive frontend recreation of the Microrage Solutions website built for learning and practice purposes using React and JavaScript.

## 🚀 Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5
- CSS3

## 📌 Project Overview

This project is a frontend clone of the Microrage Solutions website. The goal was to practice modern React development by recreating the website's user interface, responsive layouts, reusable components, animations, and overall user experience.

## ✨ Features

- Responsive design
- Modern UI components
- Smooth scrolling and animations
- Reusable React components
- Clean and organized project structure

## 🎯 Purpose

This project was created for educational and portfolio purposes only to improve React and frontend development skills.
